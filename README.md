## Projets
L'ensemble de ces projets ont été réalisés dans le cadre de ma formation développeur d'application Python.

[SoftDesk](https://github.com/yobtrd/softdesk)  
API RESTful sécurisée pour la gestion collaborative de problèmes et tâches techniques
- Gestion hiérarchique des ressources et permissions granulaires
- Sécurité renforcée et conformité OWASP, RGPD, Green Code
- Développement avec Django Rest Framework

[Litrevu](https://github.com/yobtrd/litrevu)  
Application web communautaire de partage de critiques littéraires
- Gestion des comptes utilisateurs, publications et flux personnalisés
- Fonctionnalités de réseau social : follow/unfollow
- Développement avec Django et Tailwind
- Accessibilité conforme au référentiel WCAG

[Chess Center](https://github.com/yobtrd/chess_center)  
Application de gestion de tournoi d'échec fonctionnant via une interface en ligne de commande.
- Gestion des joueurs, appariements et scores
- Développement en Python orienté objet (POO)
- Architecture MVC
- Respect des conventions PEP-8

[JustStreamIt](https://github.com/yobtrd/JustStreamIt)  
Front-end d'une application web permettant de visualiser des classements de films.
- Mise en page responsive avec CSS (Grid & Flexbox)
- Consommation d'une API REST en JavaScript (fetch)
- Gestion dynamique de l'interface : filtrage, affichage conditionnel et manipulation du DOM
- Validation HTML5/CSS3 via W3C Validator

[Invest Finder](https://github.com/yobtrd/invest_finder)  
Application en ligne de commande permettant de tester plusieurs algorithmes afin de résoudre un problème de sac à dos.
- Implémentation de différents algorithmes : force brute, glouton, programmation dynamique (bottom-up et top-down).
- Exécution sur différents datasets au format CSV
- Outils de benchmark pour analyser les performances temporelles et spatiales

[Books to Scrape](https://github.com/yobtrd/ETL_BooksToScrape)  
Version bêta d'une application visant à surveiller les prix de sites concurrents concernant des livres d'occasions.
- Extraction et transformation des données (pipeline ETL)
- Web scraping avec Beautiful Soup
- Export des données des livres et des prix au format CSV
